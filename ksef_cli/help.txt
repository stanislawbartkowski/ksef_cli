Wywołanie:
  python -m ksef_cli <akcja> <nip> <plik_na_wynik> <dodatkowe_parametry>

Wersja 1.1.6r1 z dnia 18 maja 2026 roku.

Akcje:
  wyslij_fakture Wysłanie faktury do system KSeF 2.0
  odczytaj_upo Odczytaj plik UPO do wysłanej i zaakceptowanej faktury
  pobierz_zakupowe Odczytaj nagłówki (metadata) faktur zakupowych
  pobierz_sprzedazowe Odczytaj nagłówki (metadata) faktur sprzedażowych
  odczytaj_fakture Odczytaj fakturę na podstawie nadanego numeru KSeF
  wyczysc_dane Wyczyść lokalne dane dla NIPu (dla celów testowych)
  wyslij_wsadowo Wyślij paczkę faktur w trybie wsadowym
  pobierz_zbiorczo Odczytaj zbiorczo paczkę faktur
  daj_zakupowe_bufor Odczytaj faktury zakupowe z bufora zakupowych
  uaktualnij_zakupowe_bufor Ukatualnij bufor faktur zakupowych
  wez_faktura_bufor Podaj ścieżkę do faktury zakupowej

Nip:
  Numer NIP użytkownika KSeF 2.0. NIP musi mieć odpowiednik z pliku konfiguracyjnym

Plik_na_wynik:
  Plik gdzie będzie zapisany wynik operacji. Jest to plik formacie JSON, który zawiera dla każdej operacji dwie informacje oraz informacje specyficzne dla akcji
    OK: true/fals Akcja zakończona sukcesem lub niepowodzeniem
    errmess: Jeśli akcja zakończona niepowodzeniem, to informacja o błędzie

wyslij_fakture
  python -m ksef_cli wyslij_fakture <nip> <plik_na_wynik> <plik XML z fakturą do wysłania>

  Zwraca w plik_na_wynik
    OK: true/false
    errmess
    numer_ksef: Jeśli faktura została zaakceptowana, to zawiera nadany przez KSeF 2.0 numer faktury

wyslij_wsadowo
  python -m ksef_cli wyslij_wsadowo <nip> <plik_na_wynik> <katalog z paczką faktur>

  Zwraca w plik_na_wynik
    OK: true/false
    errmess
    invoices: Lista wysłanych faktur z numerem KSeF oraz wynikiem przesłania

odczytaj_upo
  python -m ksef_cli odczytaj_upo  <nip> <plik_na_wynik> <numer_ksef>

  Zwraca w plik_na_wynik
    OK: true/false
    errmess
    upo: plik z UPO w formacie XML

odczytaj_fakture
  python -m ksef_cli odczytaj_fakture  <nip> <plik_na_wynik> <numer_ksef>

  Zwraca w plik_na_wynik
    OK: true/false
    errmess
    invoice: plik z odczytaną fakturą w formacie XML

pobierz_zakupowe
pobierz_sprzedazowe
  python -m ksef_cli pobierz_zakupowe  <nip> <plik_na_wynik> <data_od> <data_do>
  python -m ksef_cli pobierz_sprzedazowe  <nip> <plik_na_wynik> <data_od> <data_do>

  data_od: Początkowa data faktur do oczytania w formacie YYYY-MM-DD
  data_do: Data końcowa przedziału dat

  Zwraca w plik_na_wynik
    OK: true/false
    errmess
    faktury: plik w formacie JSON z listą odczytanych nagłówków faktur zakupowych lub sprzedażowych

wyczysc_dane
  python -m ksef_cli pobierz_zakupoe  <nip> <plik_na_wynik> <data_od> <data_do>

pobierz_zbiorczo
  python -m ksef_cli pobierz_zbiorczo  <nip> <plik_na_wynik> <data_od> <data_do> <subject>

  data_od: Data początkowa paczki faktur w formacie YYYY-MM-DD
  data_do: Data końcowa
  subject: Subject1, Subject2

  Zwraca w plik_na_wynik
    OK: true/false
    errmess
    katalog: Katalog tymczasowy, gdzie znajdują się odczytane faktury lub None, jeśli nic nie odczytano
    liczba_faktur: Liczba odczytanych faktur. Liczba może być 0, wówczas katalog jest None

daj_konfiguracje
  python -m ksef_cli daj_konfiguracje  <nip> <plik_na_wynik>

  Zwraca w plik_na_wynik
    OK: true/false
    errmess
    auth: Metoda autentykacji, token lub certyfikat
    mess: Komunikat, NIP jest lub nie jest skonfigurowany

daj_zakupowe_bufor
  python -m ksef_cli daj_zakupowe_bufor  <nip> <plik_na_wynik>

  Zwraca w plik_na_wynik
    OK: true/false
    errmess
    invoices: Lista metadanych dla faktur zakupowych w buforze
    ostatnia_data: Data ostatniej faktury w buforze

uaktualnij_zakupowe_bufor
  python -m ksef_cli uaktualnij_zakupowe_bufor  <nip> <plik_na_wynik>

  Zwraca w plik_na_wynik
    OK: true/false
    errmess
    liczba_faktur: Liczba nowo odczytanych faktur, może być 0, jeśli żadna nowa faktura się nie pojawiła

wez_faktura_bufor
  python -m ksef_cli wez_faktura_bufor  <nip> <plik_na_wynik> <numer_ksef>

  Zwraca w plik_na_wynik
    OK: true/false
    errmess
    faktura_path: pełna ścieżka do pliku XML z treścią faktury KSeF
